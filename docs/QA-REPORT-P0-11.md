## 阻塞项与复现信息

### P0-11-002：微信开发者工具回归和真机证据缺失

- 复现步骤：打开微信开发者工具，导入 `dist`，使用 `ops_p0_001` 进入运营配置；依次执行读取、新增、编辑、保存失败、回滚、断网恢复、刷新结果页，并在 Android 与 iPhone 真机重复；记录截图、录屏、设备型号、系统版本和构建版本。
- 当前结果：工作区没有可用的开发者工具服务端口，也没有 Android/iPhone 设备或运行证据，无法完成请求级和视觉级验收。
- 负责人：QA / 发布负责人。
- 目标修复版本：`0.2.0-mvp`。

### P0-11-003：真实 API 请求级联调未完成

- 复现步骤：启动后端及 PostgreSQL，执行 `POST /api/v1/auth/mock-login` 获取 `ops_p0_001` token；携带 Bearer token 请求 `GET /api/v1/ops/configs`、`POST /api/v1/ops/configs`、`PATCH /api/v1/ops/configs/{configKey}`、`POST /api/v1/ops/configs/{configKey}/rollback`，核对每个响应的 `code/message/data/requestId` 和前端字段。
- 当前结果：后端模块、迁移、控制器和单测已完成，但本轮没有运行中的 PostgreSQL/API 部署和实际 HTTP 响应记录。
- 负责人：后端负责人 / QA。
- 目标修复版本：`0.2.0-mvp`。

### CFG-009：大字号真机布局未验证

- 复现步骤：在微信开发者工具或真机将系统字号设置为 125% 和 150%，进入运营配置编辑、历史版本和诊断结果页，检查长文案、底部按钮、错误提示是否可滚动且不遮挡。
- 当前结果：仅完成代码级样式检查，缺少设备截图和录屏。
