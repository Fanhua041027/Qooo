# MVP 页面与状态矩阵

| 页面 | 正常状态 | 必须覆盖的特殊状态 | 用户恢复动作 |
| --- | --- | --- | --- |
| 登录页 | 微信一键进入 | 首次进入、隐私授权拒绝、登录中、登录失败 | 重新授权、重试、浏览隐私说明 |
| 首页 | 农场摘要、任务、最近诊断 | 无网络、没有农场、没有诊断记录、首次欢迎 | 重试、添加农场、开始诊断 |
| 拍照诊断 | 选择照片并补充作物 | 空、上传中、图片模糊、无作物主体、权限拒绝、无网络 | 重拍、仍然提交、打开设置、联网重试 |
| 诊断处理中 | 三阶段分析 | 分析较慢、诊断失败、分析中断网 | 离开等待、重新分析、保留照片 |
| 诊断结果 | 风险、判断依据、行动建议 | 低置信度、长文本、专家不在线、结果失败 | 补拍、展开详情、图文留言、重新分析 |
| 诊断历史 | 时间倒序记录 | 没有记录、无网络缓存、筛选无结果 | 开始诊断、重试、清除筛选 |
| 农场详情 | 健康度、地块、时间线 | 没有农场、没有地块、加载失败 | 添加农场、添加地块、重试 |
| 农事任务 | 待处理与已完成 | 没有任务、任务逾期、完成反馈 | 去诊断、调整时间、撤销完成 |
| 农技知识详情 | 长文、对比表、来源 | 超长标题、大字号、内容加载失败 | 调整字号、重试、返回列表 |
| 我的 | 用户、统计、设置 | 未登录、专家暂时不在线、消息为空 | 登录、提交留言、返回首页 |

## 15 项强制验收

1. 首次进入：登录页解释价值后再请求授权。
2. 正常状态：首页首屏只有“拍照诊断”一个主操作。
3. 上传中：保留图片并显示明确进度，阻止重复提交。
4. 图片模糊：说明具体问题，提供“重拍”和“仍然提交”。
5. 图片不符合要求：说明没有识别到主体，并展示拍摄方法。
6. AI 分析中：展示质量检查、症状识别、建议生成三个阶段。
7. 诊断成功：风险文字、可信度、依据和行动同时可见。
8. 诊断失败：说明照片是否保留，并提供重试和人工复核。
9. 无网络：不伪造成功，说明哪些内容可离线查看。
10. 没有诊断记录：提供“开始第一次诊断”。
11. 没有农场：提供“添加第一个农场”，允许诊断流程暂时跳过。
12. 专家暂时不在线：显示预计回复时间并允许图文留言。
13. 长文本：正文不截断，支持展开和大字阅读。
14. 权限拒绝：解释用途，提供打开微信设置的入口。
15. 操作成功反馈：创建任务、完成任务、添加地块均在 300ms 内出现反馈。

## 走查路径

从“我的 → 设计状态验收”进入状态实验室，逐项打开对应页面。验收时至少使用一台 375px 宽的小屏设备，并把微信字体调到最大；检查固定底栏、长标题、按钮和表格是否溢出。
