# 农间诊 `0.1.0` 发布说明

版本状态：MVP 原型开发版  
目标渠道：微信小程序开发者工具、内部体验版  
发布日期：待定  
文档更新：2026-09-28

## 版本目标

`0.1.0` 用于验证“发现作物异常后，用户能否快速获得辅助判断并采取行动”这一核心假设。目标体验是：

```text
拍一张作物照片
  → 查看可能问题和风险
  → 获得下一步行动建议
  → 创建农事任务
```

## 本版计划包含

- 模拟登录及基础用户状态。
- 首页“拍照诊断”主入口。
- 相机/相册选图、图片预览和重新选择。
- 图片质量提示，包括模糊、过暗和主体不清等情况。
- 异步诊断状态展示和可重试失败状态。
- 诊断结果：作物、可能问题、置信度、判断依据和风险等级。
- 分组行动建议及“辅助判断”安全说明。
- 诊断历史查看。
- 农场/地块基础上下文。
- 从诊断建议创建农事任务，并更新任务状态。
- 轻量 API、共享类型和可复现 Mock 数据。

最终实际发布内容以发布候选版本的验收结果为准。尚未完成或未通过验收的功能不能仅依据本清单宣称可用。

## 体验说明

本版本面向产品演示和内部验证，推荐使用 `user_p0_farmer_001` 测试主流程。测试账号和数据说明见 [TEST-ACCOUNTS.md](./TEST-ACCOUNTS.md)，完整测试要求见 [QA-TEST-PLAN.md](./QA-TEST-PLAN.md)。

建议演示路径：

1. 使用模拟账号登录。
2. 从首页点击“拍照诊断”。
3. 选择一张清晰的作物叶片照片。
4. 提交并查看分析状态。
5. 在结果页检查风险、依据和处理建议。
6. 把一条建议创建为农事任务。
7. 在任务页和诊断历史中确认记录。

## 数据和 AI 声明

- 当前 AI 可以由确定性 Mock 适配器提供结果，不能用于真实农业决策。
- 所有诊断内容均为辅助判断，不替代当地农技人员或专家意见。
- 当前版本不得在缺少可靠来源和规则校验时给出具体药剂剂量。
- 演示图片不得包含个人信息、精确住址或未经授权的真实农场数据。

## 当前限制

- 登录可能使用模拟流程，尚未完成正式微信 `code` 换取会话链路。
- 后端原型数据保存在进程内存中，服务重启后诊断和任务可能清空。
- 图片对象存储和服务端图片质量模型可使用 Mock；本地临时路径不能视为永久资源。
- AI 结果用于演示数据结构和交互状态，尚未完成真实模型准确率评测。
- 微信订阅消息、专家复核、语音、天气、商城、社区、物联网不属于本版本交付范围。
- 运营配置和完整权限体系尚未达到生产环境要求。
- 性能数据仅代表开发/体验环境，尚未完成生产规模压测。

## 回滚方案

如果体验版出现核心闭环不可用、数据隔离失败或农业安全提示缺失，应停止分发当前体验二维码并回退到上一可用构建。原型后端为内存数据时，回滚会丢失临时诊断和任务记录；演示前应将这一点告知测试人员，不把原型数据作为正式生产记录。
