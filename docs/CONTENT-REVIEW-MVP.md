## 审核门槛

### 农艺专家确认

- [ ] 确认五种作物的用语、时间条件和田间动作符合当地生产实际。
- [ ] 确认高风险、严重风险和检疫性疑似问题都包含复核路径。
- [ ] 确认没有药剂剂量、混配方法、统一安全间隔天数或禁限用替代说法。
- [ ] 确认缺素和生理性问题没有被写成确定诊断或固定补肥方案。
- [ ] 确认“补拍部位”和“复查时间”足够具体，老人用户可以理解。

### 产品负责人批准

- [ ] 确认每条文案都有 `code`、适用作物和适用场景。
- [ ] 确认结果页先展示行动，再展示解释和免责声明。
- [ ] 确认按钮文案是可执行动词，如“补拍叶背”“请农技员看看”。
- [ ] 确认高风险内容同时出现文字、图形标记和颜色，不依赖单一颜色。
- [ ] 确认配置版本、审批人和时间写入发布记录。

## 发布限制

未完成两方审批时，配置只能留在内容评审目录，不能复制到测试环境，也不能作为 AI 生产输出依据。审批通过后应生成签名或校验值，并记录发布人、发布时间和回滚版本。
