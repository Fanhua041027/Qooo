## 开发规则

- 每个任务必须绑定一个 PRD 编号。
- 每个 PR 必须写明“对应验收标准”和“Mock/真实实现”。
- 一个开发者同一时间只领取一个 `进行中` P0 任务。
- `P1/P2` 需求只允许补充说明，不允许插入当前迭代。
- 产品负责人每天只发布一个新的最高优先级。
