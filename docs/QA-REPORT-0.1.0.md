## 发布前必须完成

1. 修复 BUG-001～BUG-004，并把状态改为“待回归”。
2. 在干净环境完成 `npm install`、`npm test`、`npm run typecheck`、`npm run build:weapp`。
3. 完成后端 `prisma generate`、类型检查、单元测试和健康检查。
4. 打开微信开发者工具“设置 → 安全设置 → 服务端口”，执行真实编译。
5. 在 iPhone 小屏、主流 Android 和低端 Android 各跑一次完整闭环。
6. 记录体验版版本号、上传时间、测试二维码、前后端提交号和回滚版本。

只有在 P0 为 0、未豁免 P1 为 0，且真机闭环证据齐全后，才允许上传内部体验版。
